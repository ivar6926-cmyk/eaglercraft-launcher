Eaglercraft Launcher - Offline package

To use the launcher:
1. Extract every file from this ZIP into a folder.
2. Keep index.html, all three game HTML files, and the images folder together.
3. Open index.html in a current desktop browser.

Do not move index.html by itself. It loads the game builds and preview images from nearby files.

No cloud hosting is needed to play on this computer. Internet access is still needed for online multiplayer servers and for sending a server request by email. To share the launcher as a website, upload the entire extracted folder while preserving its file structure.
